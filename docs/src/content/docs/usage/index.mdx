`starlight-llms-tree` writes one Markdown endpoint per published Starlight page plus recursive `llms.txt` indexes after `astro build`.

## Requirements

- Node.js 22.12 or later.
- Astro 7.0.2–7.x.
- Starlight 0.41.6–0.41.x.
- Static Starlight build with root docs page.

## Install

```sh
npm install starlight-llms-tree
```

Add plugin to existing Starlight integration:

```js
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import { starlightLlmsTree } from 'starlight-llms-tree';

export default defineConfig({
  integrations: [starlight({
    title: 'Docs',
    plugins: [starlightLlmsTree()],
  })],
});
```

Run normal static build:

```sh
npm run build
```

See [configuration](./configuration/) for options and [output](./output/) for generated files.
