`starlight-llms-tree` makes static Starlight documentation directly traversable and readable by LLM clients.

## What the plugin does

During `astro build`, plugin reads final published Starlight routes and adds a parallel LLM-friendly output tree:

- each published page gets a Markdown endpoint;
- root and nested folders get `llms.txt` indexes;
- indexes expose page tags and aggregated folder scopes for discovery;
- internal links point to generated Markdown and folder indexes.

LLM client starts at root `llms.txt`, chooses relevant folder from its scopes, follows nested indexes, then fetches only needed Markdown pages. Plugin runs at build time: it does not change rendered site pages or add runtime server endpoints.

## Requirements

- Node.js 22.12 or later.
- Astro 7.0.2–7.x.
- Starlight 0.41.6–0.41.x.
- Static Starlight build with root docs page.

## Install

```sh
npm install @tigorhutasuhut/starlight-llms-tree
```

Add plugin to existing Starlight integration:

```js
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import { starlightLlmsTree } from '@tigorhutasuhut/starlight-llms-tree';

export default defineConfig({
  integrations: [starlight({
    title: 'Docs',
    plugins: [starlightLlmsTree()],
  })],
});
```

Run normal static build:

```sh
npm run build
```

See [configuration](./configuration/) for options and [output](./output/) for generated files.
