`starlight-llms-tree` turns a static Starlight build into a recursively traversable Markdown tree for LLM clients.

## Start here

```sh
npm install starlight-llms-tree
```

Add `starlightLlmsTree()` to Starlight `plugins`, then run normal static build. Plugin writes root and folder `llms.txt` indexes plus one Markdown endpoint per published docs page.
