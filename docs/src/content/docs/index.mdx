## Build once. Traverse every folder.

`starlight-llms-tree` adds LLM-friendly artifacts to normal static Starlight builds:

- recursive `llms.txt` indexes from root to nested folders;
- one Markdown endpoint per published docs page;
- final links that respect Astro `site`, `base`, and public routes.

## Start with existing Starlight config

```sh
npm install @tigorhutasuhut/starlight-llms-tree
```

Add `starlightLlmsTree()` to Starlight `plugins`, then run normal static build. No custom content tree or runtime server required.
